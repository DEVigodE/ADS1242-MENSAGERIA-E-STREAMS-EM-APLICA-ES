# ADS1242 — Mensageria e Streams em Aplicações

Repositório de atividades práticas da disciplina **ADS1242 — Mensageria e Streams em Aplicações**.

---

## Sobre a Disciplina

A disciplina aborda os principais conceitos e ferramentas de mensageria e streaming utilizados em arquiteturas de software modernas, com foco em:

- Comunicação assíncrona entre sistemas
- Padrões Producer / Consumer e Publish / Subscribe
- Brokers de mensagens (ActiveMQ, RabbitMQ, Kafka, etc.)
- Processamento de streams em tempo real
- Integração de aplicações via JMS e outros protocolos
